# roeehrl's Scoop bucket

[hopsesh](https://github.com/roeehrl/hopsesh): move Claude Code and Codex sessions between
your machines and agents.

```powershell
scoop bucket add roeehrl https://github.com/roeehrl/scoop-bucket
scoop install hopsesh
```

The manifest is written by hopsesh's release workflow for each published release; changes
made here are overwritten. Issues go to [roeehrl/hopsesh](https://github.com/roeehrl/hopsesh/issues).
hopsesh is unofficial and not affiliated with Anthropic or OpenAI.
